# 智能推荐策略评估（2026-07-01 ~ 07-24 实测窗口）

> 评估目标：测试当前智能推荐策略在评估周期内是否仍有优化点。
> 数据来源：`stock_recommendation` 表（实际仅有 2026-07-01~07-24 共 7608 条推荐记录）。
> **重要约束**：用户要求的 2026-01-01~07-24 中，**01-01~06-30 没有任何推荐记录**，真实可评估窗口仅为 07-01~07-24。该窗口绝大多数为"修复前"老策略产物（高置信门槛/熊市反转/分位排名于 07-24 才上线），故本评估同时反映老策略缺陷与新修复方向。

## 一、核心结论

策略整体接近"次日零超额、胜率 49.5%"的硬币翻转水平，但**信号高度集中在高分档且被噪声档拖累**。四个可量化优化点按影响力排序：

1. **STATIC 权重模式占 49% 且各策略均匀** —— ICW 全面优于 STATIC（日超额 +0.154% vs -0.216%），应默认全切 ICW。
2. **熊市（BEAR）是真正的漏点** —— 即便高置信（final≥0.70）仍日亏 -0.63%、胜率仅 44.5%，老策略在此毫无防御。
3. **顶端档（final≥0.9）反常踩雷** —— 集中高 beta 科创/成长股（华海清科次日 -11.9% 等），需限仓或加波动惩罚。
4. **差策略（74/82/77/81/89）净负拖累** —— 与 STATIC 占比无关（各策略 STATIC 均匀 ~50%），应单独排查因子配置或砍掉。

## 二、量化证据

### 2.1 全量基准（有次日超额数据的 7317 条）
| 指标 | 值 |
|---|---|
| 次日超额均值 | -0.027% |
| 次日胜率 | 49.5% |
| 次周超额均值 | -0.512% |

> 整体次日接近零，但次周为负 → 信号偏极短端，噪声档把周收益拖绿。

### 2.2 final_score 分档单调性（高置信阈值有效性的直接验证）
| 分档 | n | 次日超额 | 次日胜率 |
|---|---|---|---|
| [0,0.5) | 255 | +0.815% | 50.6% |
| [0.5,0.6) | 2032 | **-0.539%** | **42.7%（最差）** |
| [0.6,0.7) | 2695 | +0.018% | 49.6% |
| [0.7,0.8) | 1906 | +0.172% | 54.5% |
| [0.8,0.9) | 414 | **+0.807%** | **58.7%（最佳）** |
| [0.9,1] | 15 | -1.475% | 40.0%（样本极小，异常） |

- 单调性在 [0.5,0.9) 成立：0.5~0.6 是噪声死区，0.8~0.9 是甜点区。
- **高置信门槛（≥0.70）验证有效**：≥0.70 胜率 55.1%/+0.274% vs <0.70 胜率 46.8%/-0.169%。
- 顶端档反常：仅 15 条且集中在高波动个股，不可靠。

### 2.3 权重模式：STATIC vs ICW（最大可优化点）
| 模式 | n | 次日超额 | 次日胜率 | 次周超额 |
|---|---|---|---|---|
| STATIC | 3579 | -0.216% | 46.5% | -1.563% |
| ICW | 3738 | **+0.154%** | **52.3%** | **+0.526%** |

- ICW 在日、周、胜率三维全面胜出，差距约 0.37%/日、5.8pp 胜率。
- STATIC 占 49%，且**各策略均匀（45%~63%）**，并非差策略专属 → 全切 ICW 可系统性抬升每策略。
- 注意：ICW 的优势主要来自保护"噪声档（<0.70）"；在高置信区间内两者差距收窄（ICW +0.245% vs STATIC +0.433% 日超额，但 ICW 胜率更高 55.5% vs 52.9%）。

### 2.4 分策略（按次日超额排序，n≈540~605）
- 最佳：86(+0.648%/52.5%)、87(+0.188%/55.2%)、73(+0.127%/52.9%)
- 最差：74(-1.042%/39.3%)、82(-0.297%/43.9%)、77(-0.178%/44.0%)、81(-0.148%/47.4%)、89(-0.039%/50.7%)
- 最差 5 个策略均为净负，显著拖累组合；其 STATIC 占比与好策略无异 → 问题在因子配置而非权重模式。

### 2.5 Regime 维度（熊市是漏点）
| Regime | n | 次日超额 | 次日胜率 |
|---|---|---|---|
| BULL | 499 | +1.942% | 76.6% |
| SIDEWAYS | 5498 | -0.131% | 48.3% |
| BEAR | 1320 | **-0.338%** | **44.0%** |

- BEAR 下即使高置信（≥0.70）仍日亏 -0.63%、胜率 44.5%（ICW -0.63%/44.98% vs STATIC -0.89%/44.12%，ICW 略好但仍亏）。
- 老策略熊市无有效防御，新加的"熊市动量反转（07-24 上线）"需后续用新数据验证，本窗口无法确认其是否有效。

### 2.6 顶端档异常个股（final≥0.9）
华海清科(688120) -11.89%、华虹宏力(688347) -6.9%、昭衍新药(603127) -6.39%、药明康德(603259) -1.57% 等 —— **集中于 688/300 高波动成长股**，高分但次日大幅回撤。另发现同股同日的重复记录（数据质量小瑕疵）。

## 三、优化点清单（按影响力）

| # | 优化点 | 预期提升 | 难度 |
|---|---|---|---|
| 1 | **默认全切 ICW，取消 STATIC 模式**（或 STATIC 仅作对照） | 整体日超额 +0.37%、胜率 +5.8pp | 低（配置/代码开关） |
| 2 | **熊市防御**：BEAR 下降仓（如 position×0.5）或暂停生成；验证 07-24 熊市反转是否真正生效 | 堵住最大单点漏损 | 中 |
| 3 | **高 beta/688-300 限仓或加波动惩罚**：限制单票波动/涨跌幅上限，避免顶端档踩雷 | 修复顶端档 -1.475% 异常 | 中 |
| 4 | **排查/砍掉净负策略**（74/82/77/81/89）或单独重配其因子 | 移除拖累项 | 中（需逐策略诊断） |
| 5 | **高置信阈值可从 0.70 提到 0.75**：[0.8,0.9) 甜点区胜率 58.7% 明显优于 [0.7,0.8) 的 54.5% | 进一步提升入选质量 | 低 |

## 四、关于"2026-01-01~07-24"评估周期

- 推荐记录实际仅 07-01~07-24，01-01~06-30 为空。
- 若要覆盖完整周期，需**用当前（已修复）代码对 01-01~07-24 每个交易日做历史回测重算**（重新生成推荐并追踪收益）。这是一次性的 DB 写入型重算，约 130 个交易日 × 多策略，较重，需确认后执行。
- 更轻量的替代：用 `factor_value` + `stock_daily`（CH 中均有 01 月起数据）在 Python 中复刻 ICW+高置信管线做纯只读回测，不污染生产库。
